# Скрипты

Всё запускаемое лежит здесь: разборы заездов на Python, симулятор, визуализатор,
shell-обвязка сборки и статический анализ C++. Подкаталоги — по задаче, `core/` — общая
библиотека, которую импортируют остальные, `pyadas/` — собранный C++ модуль, его кладёт сюда сборка.

Начинать почти всегда с одного:

```bash
python3 bag/bag_report.py ../adas_logs/<заезд>
```

Первый прогон по заезду около 95 секунд, дальше 0.3 с — всё считается по кэшу
(`vis/bag_cache.py`). Разделы выбираются: `--only step,torque`. Подробности — `docs/BAG_ANALYSIS.md`.

Остальное нужно, когда `bag_report` показал, куда смотреть.

## Разбор заезда

| скрипт | на какой вопрос отвечает |
|---|---|
| `bag/bag_report.py` | сводка: темп зрения, шаг уставки, упор по моменту, уверенность разметки, поза, голосовые пометки |
| `bag/bag_voice_notes.py` | что водитель говорил вслух и на какой секунде |
| `tools/latency.py` | подробная разбивка задержек по этапам конвейера |
| `bag/bag_middleware_stats.py` | не опаздывают ли таймеры сервисов |
| `bag/bag_arc_offset.py` | почему машина не по центру на дуге: сколько от слежения, сколько от опоры |
| `bag/bag_override_episodes.py` | где водитель перехватывал руль и что в этот момент просил контроллер |
| `bag/bag_safety_warn.py` | срабатывания FCW / AEB / LDW |
| `bag/bag_speed_sources.py` | расхождение источников скорости: колёса, фильтр, ГНСС |

## Сравнение с comma

| скрипт | |
|---|---|
| `rlog/rlog_lat_diff.py` | наш поперечный тракт против их логов на той же машине |
| `rlog/rlog_arc_offset.py` | та же метрика смещения, что `bag_arc_offset`, но по их логам |

Обоим нужен `OPENPILOT_ROOT` — путь к дереву openpilot/dragonpilot, откуда берётся `cereal`.

## Офлайн-проверки перед заездом

Гоняют настоящий C++ через `pyadas`, поэтому меряют то, что поедет, а не его пересказ.

| скрипт | |
|---|---|
| `bag/bag_controller_ab.py` | pp против mpc против fp на одном окне записи |
| `bag/bag_config_sweep.py` | замкнутый перебор настроек удержания полосы |
| `bag/bag_lane_keep_offline.py` | удержание полосы через симулированный AdasApp |
| `bag/bag_mpc_sim.py` | замкнутый и теневой симулятор MPC |
| `bag/bag_feedforward_ab.py` | что изменит другое упреждение — **разомкнуто**, читать как верхнюю границу |
| `bag/bag_long_replay.py` | правила продольного плана на записи: старое поведение против нового |
| `bag/bag_long_sim.py` | лид, продольный план и предупреждения из сырого выхода модели |
| `bag/bag_coast_decel.py` | какое замедление машина даёт без тормозов |
| `bag/bag_lane_sigma_ab.py` | σ разметки между заездами на сопоставимых условиях |

## Статический анализ

`cpp/` — прогон clang-tidy по коду C++ и отчёты с приоритетами находок. Запускается из
`app/src/main/cpp`, потому что там лежат `.clang-tidy` и база компиляции; как именно —
[`cpp/README.md`](cpp/README.md).

## Служебное

`_path.py` — общий путь к `pyadas` и `vis`, импортируется первым во всех разборах.
`generate_proto_python.sh` — перегенерация питоновских протобуфов.
`requirements.txt` — зависимости разборов.

Скрипты из `bag/`, `rlog/` и `tools/` запускаются файлом, из `sim/`, `vis/` и `mapmatch/` —
модулем (`python3 -m sim.eval …`) из этого каталога.
