# Атрибуция

Рисунки в `Control/figures/` (PNG) и `Vision/figures/` взяты из
[Algorithms for Automated Driving](https://github.com/thomasfermi/Algorithms-for-Automated-Driving)
(CC BY 4.0) либо сделаны для этого курса.

Тем, кто читает в VS Code или Cursor: главы используют обычные картинки Markdown, чтобы превью их показывало.
Блоки MyST `{figure}` намеренно не используются — в редакторе они не отображаются.
Jupyter Book при этом прекрасно собирает и обычные картинки Markdown.
