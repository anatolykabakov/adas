# Скрипты

Начинать почти всегда с одного:

```bash
python3 bag_report.py ../../../../adas_logs/<заезд>
```

Первый прогон по заезду около 95 секунд, дальше 0.3 с — всё считается по кэшу
(`vis/bag_cache.py`). Разделы выбираются: `--only step,torque`. Подробности — `docs/BAG_ANALYSIS.md`.

Остальное нужно, когда `bag_report` показал, куда смотреть.

## Разбор заезда

| скрипт | на какой вопрос отвечает |
|---|---|
| `bag_report.py` | сводка: темп зрения, шаг уставки, упор по моменту, уверенность разметки, поза, голосовые пометки |
| `bag_voice_notes.py` | что водитель говорил вслух и на какой секунде |
| `latency.py` | подробная разбивка задержек по этапам конвейера |
| `bag_middleware_stats.py` | не опаздывают ли таймеры сервисов |
| `bag_arc_offset.py` | почему машина не по центру на дуге: сколько от слежения, сколько от опоры |
| `bag_override_episodes.py` | где водитель перехватывал руль и что в этот момент просил контроллер |
| `bag_safety_warn.py` | срабатывания FCW / AEB / LDW |
| `bag_speed_sources.py` | расхождение источников скорости: колёса, фильтр, ГНСС |

## Сравнение с comma

| скрипт | |
|---|---|
| `rlog_lat_diff.py` | наш поперечный тракт против их логов на той же машине |
| `rlog_arc_offset.py` | та же метрика смещения, что `bag_arc_offset`, но по их логам |

Обоим нужен `OPENPILOT_ROOT` — путь к дереву openpilot/dragonpilot, откуда берётся `cereal`.

## Офлайн-проверки перед заездом

Гоняют настоящий C++ через `pyadas`, поэтому меряют то, что поедет, а не его пересказ.

| скрипт | |
|---|---|
| `bag_controller_ab.py` | pp против mpc против fp на одном окне записи |
| `bag_config_sweep.py` | замкнутый перебор настроек удержания полосы |
| `bag_lane_keep_offline.py` | удержание полосы через симулированный AdasApp |
| `bag_mpc_sim.py` | замкнутый и теневой симулятор MPC |
| `bag_feedforward_ab.py` | что изменит другое упреждение — **разомкнуто**, читать как верхнюю границу |
| `bag_long_replay.py` | правила продольного плана на записи: старое поведение против нового |
| `bag_long_sim.py` | лид, продольный план и предупреждения из сырого выхода модели |
| `bag_coast_decel.py` | какое замедление машина даёт без тормозов |
| `bag_lane_sigma_ab.py` | σ разметки между заездами на сопоставимых условиях |
| `model_ab_sim.py` | две модели зрения на одном баге |

## Служебное

`generate_proto_python.sh` — перегенерация питоновских протобуфов.
`requirements.txt` — зависимости разборов.
