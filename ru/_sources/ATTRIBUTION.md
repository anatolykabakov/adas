# Атрибуция

Рисунки в `Control/figures/` (PNG) и `Vision/figures/` либо взяты из
[Algorithms for Automated Driving](https://github.com/thomasfermi/Algorithms-for-Automated-Driving)
(CC BY 4.0), либо сделаны специально для этого курса.

Тем, кто читает в VS Code или Cursor: в главах используются обычные картинки Markdown, чтобы их было видно в превью.
Блоки MyST `{figure}` мы намеренно не применяем — в редакторе они не отображаются.
При этом Jupyter Book прекрасно собирает и обычные картинки Markdown.
